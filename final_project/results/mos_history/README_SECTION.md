### Guidance over the whole training window (long-record MOS)

The 2010-2023 failure above could come from old years being unlike the test year, or from training with sources that were missing and had to be imputed. To tell these apart we used station guidance that exists in every year: GFS MOS (MAV) and NAM MOS (MET) from the Iowa Environmental Mesonet archive (`mos.py`, 57 model-years with URL, row count and SHA-256 in `data/mos_sources.csv`).
Both products cover every year from 2008 to 2026. GFS is missing 1 of 6,817 dates and NAM 11, and the archive stores only the 00 and 12 UTC NAM runs. MEX starts on 2020-07-11, so it is used only in the 2021-2023 models. The earlier probe's empty day in 2012 does not reflect a gap for the year.
For each date and cutoff, `data/mos_features.csv.gz` uses the newest run released by the cutoff, assuming release 5 h after initialization (6 h for MEX). It records the daytime maximum, the highest 3-hourly projection before local midnight, the projection interpolated to the cutoff (compared with the latest LGA reading), and sky cover and wind. Tests check every run used against its assumed release time, and check that the run chosen at noon changes when daylight saving time starts or ends.
Without imputation, more history does help. Stations + trends + GFS and NAM MOS, trained on 2010-2023 and scored on the same 359 test days, beats the same model trained on 2021-2023. The log loss improvement is 0.029 at 09:00 (95% 7-day block-bootstrap interval 0.009 to 0.052) and 0.022 at 12:00 (0.007 to 0.041), with no difference at 15:00 (0.002, interval -0.005 to 0.009). The GFS-only model shows the same pattern.
The 2024 validation year does not show this gain for the GFS + NAM model: it prefers the 2018-2023 window at 09:00 and the 2021-2023 window at 12:00. The long MOS model also stays behind CURRENT on validation at every cutoff (0.268 / 0.198 / 0.111 against 0.211 / 0.171 / 0.098), even though on test it comes within 0.004 / 0.020 / 0.008.
Three ways of combining the long record with CURRENT do not clearly help. Each change below is in test log loss relative to CURRENT, at 09:00 / 12:00 / 15:00.
Adding GFS, NAM and MEX features to CURRENT's 2021-2023 model changes test log loss by -0.009 / +0.001 / +0.003.
In a two-stage model, the 2010-2023 MOS model's mean and log sigma (out-of-fold for the 2021-2023 training years) are fed to CURRENT as two extra inputs. This changes test log loss by -0.010 / -0.002 / +0.001.
A weighted average with weights chosen on validation puts weight 0 / 0.1 / 0.1 on the long model and is indistinguishable from CURRENT.
Validation selects CURRENT + MOS at 09:00 and 12:00 and the two-stage model at 15:00. Their test log loss is 0.1905 / 0.1603 / 0.0734, against CURRENT's 0.1995 / 0.1591 / 0.0722.
None of the paired intervals excludes zero. The closest is the two-stage model at 09:00 (-0.021 to 0.000). CURRENT therefore remains the reported system, and the measurable value of a longer record so far is in the guidance-limited model, not the final one.
