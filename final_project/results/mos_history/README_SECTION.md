### Guidance over the whole training window (long-record MOS)

The 2010-2023 failure above could come from old years being unlike the test year, or from training with sources that were missing and had to be imputed. To tell these apart we used station guidance that exists in every year: GFS MOS (MAV) and NAM MOS (MET) from the Iowa Environmental Mesonet archive (`mos.py`, 57 model-years with URL, row count and SHA-256 in `data/mos_sources.csv`).
Both products cover every year from 2008 to 2026. GFS is missing 1 of 6,817 dates and NAM 11, and the archive stores only the 00 and 12 UTC NAM runs. MEX starts on 2020-07-11, so it is used only in the 2021-2023 models. The earlier probe's empty day in 2012 does not reflect a gap for the year.
For each date and cutoff, `data/mos_features.csv.gz` uses the newest run released by the cutoff, assuming release 5 h after initialization (6 h for MEX). It records the daytime maximum, the highest 3-hourly projection before local midnight, the projection interpolated to the cutoff (compared with the latest LGA reading), and sky cover and wind. Tests check every run used against its assumed release time, and check that the run chosen at noon changes when daylight saving time starts or ends.
Without imputation, the long window no longer hurts, but it does not clearly help either. On the same 359 test days, stations + trends + GFS and NAM MOS trained on 2010-2023 instead of 2021-2023 changes test log loss by -0.007 at 09:00 (95% 7-day block-bootstrap interval -0.027 to 0.011), -0.014 at 12:00 (-0.035 to 0.002) and -0.001 at 15:00 (-0.008 to 0.006). The GFS-only model looks similar. Its one interval that excludes zero is 2010-2023 against 2018-2023 at 09:00 (-0.020, -0.043 to -0.0005).
The 2024 validation year prefers the 2018-2023 window for the GFS + NAM model at all three cutoffs (0.246 / 0.183 / 0.087 against 0.264 / 0.192 / 0.088 for 2010-2023). The long MOS model also trails CURRENT on validation (0.264 / 0.192 / 0.088 against 0.187 / 0.169 / 0.082) and on test (by 0.028 / 0.027 / 0.012).
Three ways of combining the long record with CURRENT do not help. Each change below is in test log loss relative to CURRENT, at 09:00 / 12:00 / 15:00.
Adding GFS, NAM and MEX features to CURRENT's 2021-2023 model changes test log loss by -0.005 / +0.009 / +0.001.
In a two-stage model, the 2010-2023 MOS model's mean and log sigma (out-of-fold for the 2021-2023 training years) are fed to CURRENT as two extra inputs. This changes test log loss by -0.007 / +0.000 / +0.007.
A weighted average with weights chosen on validation puts weight 0 / 0.1 / 0.4 on the long model and changes test log loss by 0.000 / +0.001 / +0.001.
Validation selects CURRENT itself at 09:00, CURRENT + MOS at 12:00 and the two-stage model at 15:00. Their test log loss is 0.1818 / 0.1460 / 0.0771, against CURRENT's 0.1818 / 0.1368 / 0.0701.
The 15:00 pick is worse on test, with an interval that excludes zero (+0.007, 0.0003 to 0.015). The 12:00 pick's interval includes zero (+0.009, -0.003 to 0.021). CURRENT therefore remains the reported system. Removing imputation removes the harm from long training, but the extra years give no measurable gain.
