## Fresh HRRR: the newest run released by each cutoff

`python final_project/hrrr_fresh.py fetch` and `build` replace the fixed 10 UTC HRRR run with the newest hourly run whose 2 m temperature tile (same Utah hrrrzarr archive, grid point and S3 Last-Modified rule as `hrrr.py`) was archived by the cutoff and whose leads reach local midnight; point series are cached in the gitignored `data/raw/hrrr_fresh/`, and the bundled tables are `data/hrrr_fresh_cycles.csv.gz` and `data/hrrr_fresh_features.csv.gz`.
The archive writes each run about 2 hours after initialization, so on test days the fresh run is on average 2.1 / 2.0 / 2.1 h old at 09:00 / 12:00 / 15:00, against 3.3 / 6.3 / 9.3 h for the 10 UTC run.
A fresh run exists on 359 / 359 / 359 of the 359 test days, so the 10 UTC fallback is never needed on test, and on 277 / 277 / 277 of the 277 validation days.
Freshness helps the raw forecast: HRRR's error at the cutoff hour against the latest LGA reading falls from 1.68 / 1.95 / 2.04 F to 1.57 / 1.73 / 1.55 F on 2024 days, and the test MAE of max(high so far, HRRR remaining max) for the final high falls from 2.02 / 1.97 / 1.42 F to 1.96 / 1.88 / 1.15 F.
`python final_project/hrrr_fresh_study.py` (offline, under a minute) refits CURRENT, the censored Gaussian on stations + trends + HRRR + LAMP/NBM, with (a) the fresh run replacing the 10 UTC features and (b) the fresh run added beside them, trained on 2021-2023 complete rows and tuned on 2024.
Validation log loss: CURRENT 0.187 / 0.169 / 0.082, (a) 0.186 / 0.180 / 0.091, (b) 0.185 / 0.174 / 0.086, so validation selects (b) at 09:00, CURRENT at 12:00, CURRENT at 15:00.
At 09:00 both fresh variants edge CURRENT on validation (by 0.001 for (a) and 0.002 for (b)); at 12:00 and 15:00 their deficit (+0.011 / +0.009 for (a), +0.005 / +0.004 for (b)) sits in a few confident misses and becomes -0.003 / -0.002 and -0.005 / -0.001 without each one's three worst days (`validation_concentration.csv`); trimming flatters any system, so this describes the gap and does not override the selection.
On the same 359 test days, log loss is CURRENT 0.182 / 0.137 / 0.070, (a) 0.180 / 0.143 / 0.075, (b) 0.183 / 0.139 / 0.065; RPS 0.0563 / 0.0425 / 0.0201, 0.0548 / 0.0434 / 0.0196, 0.0553 / 0.0418 / 0.0187; accuracy 92.5% / 94.7% / 97.5%, 92.8% / 94.4% / 97.5%, 92.8% / 94.2% / 97.8%.
Paired log loss differences against CURRENT with 95% 7-day block intervals: (a) -0.001 [-0.017, +0.011], +0.006 [-0.007, +0.019], +0.005 [-0.011, +0.030]; (b) +0.001 [-0.010, +0.010], +0.002 [-0.010, +0.014], -0.005 [-0.013, +0.004]. Every interval includes zero, and the validation pick ((b) at 09:00, CURRENT at 12:00 and 15:00) scores 0.183 / 0.137 / 0.070 on test, so the fresh run neither helps nor hurts detectably.
The refit CURRENT matches the saved guidance-study test probabilities to 1.1e-16.
`test_hrrr_fresh.py` checks that no bundled run was archived after its cutoff and no newer qualifying run was skipped, the daylight-saving cutoffs and the lead window. Last-Modified is when Utah's archive wrote the tile, a conservative stand-in for public release, and dates rewritten later in the archive have no qualifying run (344 of 6207 date-cutoffs from 2021 to August 2026, 76% of them in 2024).
