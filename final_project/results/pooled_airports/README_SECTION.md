## Pooling nearby airports as training targets

`python final_project/pooled_airports.py all` (build about 1 minute from cached raw files, run under 20 seconds) adds JFK, EWR and TEB as training targets for the censored Gaussian without HRRR: each airport's own label (prepare.py's rule), its own observations and LAMP/NBM guidance as the "own" inputs, the other three airports by distance as neighbour inputs. Training uses the same 2021-2023 dates as CURRENT (1,040 LGA rows, 4,153 pooled at 09:00); L2 and an LGA weight are chosen on 2024 LGA validation; test is the same 359 LGA days.

- Test log loss (09:00 / 12:00 / 15:00): LGA only 0.168 / 0.131 / 0.076, pooled 0.167 / 0.134 / 0.080, pooled with airport intercept shifts 0.168 / 0.133 / 0.079, the same with an LGA weight 0.168 / 0.133 / 0.079; CURRENT with HRRR 0.182 / 0.137 / 0.070. Validation: LGA only 0.201 / 0.186 / 0.093, pooled 0.200 / 0.186 / 0.092, CURRENT 0.187 / 0.169 / 0.082.
- Pooled minus LGA only: -0.000 [-0.011, +0.011]; +0.003 [-0.003, +0.010]; +0.004 [-0.002, +0.010] (95% 7-day block intervals). Pooled minus CURRENT: -0.015 [-0.044, +0.013]; -0.003 [-0.017, +0.010]; +0.009 [-0.005, +0.030].
- Validation picks, without HRRR: 09:00 Pooled + airport shifts + LGA weight +0.000 [-0.009, +0.010]; 12:00 Pooled + airport shifts +0.002 [-0.005, +0.008]; 15:00 Pooled + airport shifts + LGA weight +0.003 [-0.005, +0.010] against LGA only; the interval excludes zero at no cutoff. With CURRENT among the candidates, validation selects CURRENT at every cutoff.
- Same number of rows, different rows: the pool subsampled to the LGA count (five draws, about a quarter LGA) scores validation 0.201 / 0.195 / 0.094 and test 0.167 / 0.135 / 0.080. Using all pooled rows instead changes validation by -0.001 / -0.009 / -0.002 and test by +0.001 / -0.001 / -0.001.
- Airport intercept shifts are small (largest 0.6 F of rise at equal inputs), so each airport's own observations and guidance already carry most of the difference between airports.

The extra rows are the same days at airports 11 to 21 miles apart, so they repeat LGA's weather and are far from independent samples. Checks (`test_pooled_airports.py`): rebuilt LGA labels and features equal the bundled samples in every cell; rebuilt KLGA guidance equals the bundled table; no LAMP or NBM run is used before its assumed release at any airport; the LGA-only refit matches guidance_study.py's saved no-HRRR model to 0.000 in any band probability.
